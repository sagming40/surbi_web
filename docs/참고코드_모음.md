## 1. Riverpod 표준 패턴 (EPIC 1 · Task 1-3)

**Provider 대신 Riverpod을 선택한 이유**
- `Provider`는 `BuildContext`에 묶여 있어 Web 라우팅 변경 시 상태 소실 위험
- `Riverpod`은 Context 없이 어디서든 접근 가능 → Flutter Web에 적합
- `AsyncNotifier`로 로딩 / 에러 / 데이터 상태를 한 번에 관리

**모든 화면에서 쓰는 표준 패턴** (API 연동 후 적용 대상)

```dart
final state = ref.watch(areaNotifierProvider);
state.when(
  loading: () => const SurbiLoading(message: '상권 데이터 불러오는 중...'),
  error:   (e, _) => SurbiError(
    message: e.toString(),
    onRetry: () => ref.refresh(areaNotifierProvider),
  ),
  data:    (areas) => AreaListView(areas: areas),
);
```

> 현재는 임시 데이터를 반환하는 동기 `Provider`라 `.when()`을 쓰지 않는다.
> EPIC 4에서 실제 API로 교체할 때 이 패턴으로 전환한다.

## 2. Firestore 컬렉션 구조 · Security Rules (Task 2-5)

> ⚠️ **선행 확인 필요** — 최신 ERD(2026-07-20)에 `users`·`favorites` 테이블이 없다.
> "PostgreSQL과 Firestore가 다른 목적으로 공존"이라는 전제가 성립하는지 DB팀 확인 후 착수.

**컬렉션 구조**

```
users/{uid}/
  ├── scraps/{scrapId}    → 관심 상권 스크랩
  └── reports/{reportId}  → AI 분석 리포트 내역
```

**Security Rules**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
```

> 핵심은 `request.auth.uid == uid` — **자기 문서만** 읽고 쓸 수 있게 한다.
> 이 한 줄이 없으면 로그인한 아무나 남의 스크랩을 읽을 수 있다.

## 3. LLM 보고서 폴링 패턴 (Task 4-6)

> ⚠️ **B4 블로커** — 보고서 입력값이 미확정이라 엔드포인트 형태가 바뀔 수 있다.

```dart
Future<String> pollReport(String reportId) async {
  for (int i = 0; i < 20; i++) {       // 최대 60초 (3초 × 20회)
    await Future.delayed(const Duration(seconds: 3));
    final res = await apiService.get('/reports/$reportId');
    final data = jsonDecode(res.body);
    if (data['status'] == 'completed') return data['content'];
  }
  throw Exception('보고서 생성 시간 초과');
}
```

> 폴링은 "다 됐나요?"를 주기적으로 물어보는 방식이다. 서버가 먼저 알려주는 방식(WebSocket 등)
> 보다 단순하지만, **끝나는 조건과 최대 횟수를 반드시 정해야** 무한 대기가 안 생긴다.
> 타임아웃 시 사용자에게 보여줄 문구는 Task 5-2 에러 케이스 점검에 포함.

## 4. CanvasKit 초기 로딩 오버레이 (Task 5-1)

> Flutter Web(CanvasKit)은 첫 방문 시 **5~8MB Wasm 다운로드**가 필요해,
> 그동안 흰 화면만 보이면 사용자가 이탈한다. `web/index.html`에 삽입.

```html
<style>
  .loading-overlay {
    position: fixed; inset: 0;
    background: #1E3A5F;
    display: flex; flex-direction: column;
    align-items: center; justify-content: center;
    z-index: 9999;
    transition: opacity 0.5s ease;
  }
  .loading-overlay.hidden { opacity: 0; pointer-events: none; }
</style>

<div class="loading-overlay" id="loading">
  <img src="icons/surbi_logo.png" width="80" alt="Surbi 로고" />
  <p style="color:white; margin-top:24px; font-family:sans-serif;">잠시만 기다려주세요...</p>
</div>

<script>
  window.addEventListener('flutter-first-frame', () => {
    document.getElementById('loading').classList.add('hidden');
  });
</script>
```

> `flutter-first-frame`은 **Flutter가 첫 화면을 실제로 그린 순간** 발생하는 이벤트다.
> 로딩이 끝난 시점을 임의의 시간(예: 3초)으로 추측하지 않고 이 신호를 쓰는 게 정확하다.
> 준비물: `web/icons/surbi_logo.png` (192×192px)

## 5. 업소 마커 클릭 → 카드 → 상세 배선 (Phase 2-D)

> **출처** — 삭제된 `lib/views/map_page.dart` (2026-08-23 · Phase 2-B에서 폐기).
> 통합 화면 `/explore`가 업소 지도를 흡수하면서 화면 파일은 지웠지만,
> **마커 클릭 배선은 Phase 2-D에서 그대로 쓸 코드**라 여기 남긴다.
>
> 카드의 실제 DOM(`_buildOverlayCardElement`)과 표시 함수는 삭제하지 않았다 —
> `lib/services/kakao_map_view_registry.dart`에 그대로 살아 있다.
> 여기 적힌 것은 **화면 쪽 배선**뿐이다.

```dart
@override
void initState() {
  super.initState();

  // 마커를 누르면 → 상태에 기록하고 지도 위에 카드를 띄운다
  onBusinessMarkerTap = (business) {
    ref.read(selectedBusinessProvider.notifier).state = business;
    showBusinessOverlay(business);
  };

  // 카드의 '상세' 버튼 → 카드를 닫고 분석 화면으로
  onBusinessDetailTap = (business) {
    closeBusinessOverlay();
    context.go('/analysis/$_currentRegionCode/${widget.categoryCode}');
  };

  WidgetsBinding.instance.addPostFrameCallback((_) async {
    await addBusinessMarkers(ref.read(businessesProvider));
  });
}

@override
void dispose() {
  // ⚠️ 반드시 해제 — 안 하면 다음 화면이 이 콜백을 물려받는다
  onBusinessMarkerTap = null;
  onBusinessDetailTap = null;
  super.dispose();
}
```

**Phase 2-D에서 달라질 점**

| | `/map` (구) | `/explore` (신) |
|---|---|---|
| 마커 데이터 | `businessesProvider` (목업 3건) | `GET /api/businesses` (Task 4-5) |
| 그릴 시점 | 화면 진입 시 1회 | **동을 고를 때마다** |
| 상세 이동 | `/analysis/...` | 패널 안에서 표시 (Phase 3) |

> ⚠️ `_currentRegionCode`는 `/map`이 화면 안에서 따로 들고 있던 값이다.
> `/explore`에는 그런 지역 상태가 없다 — **주소가 진실**이므로
> `GoRouterState.of(context).pathParameters['districtCode']`를 쓴다.
